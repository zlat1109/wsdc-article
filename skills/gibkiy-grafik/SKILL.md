# Гибкий График — практики визуализации

База правил курса «Гибкий График» (Nastengraph). Не конспект уроков: чеклисты и деревья выбора. Прогоняй таск через скилл — спроектировать или проревьюить.

Не дублирует `tableau-workflows` (экстракты, кальки, перф Tableau). Здесь визуальная грамматика.

Язык правил: русский. Термины курса дублируй EN в скобках.

## Режимы

### Спроектировать

Вход: бриф / вопрос / данные. Выход:

1. Задача восприятия (сравнить, тренд, доля, распределение, связь).
2. Тип графика и почему.
3. Какие правила из `reference/` применить (ссылки на пункты).
4. Что сознательно не делаем (3D, ось не от нуля на барчарте, и т.п.).

### Проревьюить

Вход: концепт / скрин / спека. Выход:

1. Нарушения с отсылкой к пункту в `reference/`.
2. Конкретные правки (убрать / подписать / перекодировать).
3. Что оставить: не чистить то, без чего график перестаёт читаться.

## Как применять

1. Прочитай этот файл, затем только нужный `reference/`.
2. Не пересказывай главу курса. Давай операционные указания.
3. Баланс важнее максимального data-ink: «reasonable data-ink maximizing».
4. В дэшбордах chartjunk не используем; в 1–2 журналистских графиках — можно, если инсайт держится.

## Эвристики с ДЗ

Глава 1, ДЗ 1 — канонический пример: вариант C

- Интересы: [`projects/learning/gibkiy-grafik/hw/01/youth/after.png`](../../projects/learning/gibkiy-grafik/hw/01/youth/after.png)
- Обращения: [`projects/learning/gibkiy-grafik/hw/01/claims/after.png`](../../projects/learning/gibkiy-grafik/hw/01/claims/after.png)

Применённые правила:

- Сравнение величин — горизонтальный lollipop, ось от 0, значения с `%` у точек, ось X убрана.
- Один акцент (топ-3 / пики), остальное нейтральное. Легенда в подзаголовке, не дублируется.
- Панель фильтров на статичном графике — chartjunk, убрана.
- Пики подписывать по-русски, чередовать сдвиг вверх/вниз; крайние справа — `ha=right`.
- Ось Y обращений от 0 (lie factor).
